# Bundled fonts

Latin woff2 subsets, copied into the build by Vite from `theatre.css` (no CDN, no network).

| File | Family | Weight | Licence |
|------|--------|--------|---------|
| `barlow-condensed-500.woff2` | Barlow Condensed | 500 | SIL OFL 1.1 (`OFL-BarlowCondensed.txt`) |
| `barlow-condensed-600.woff2` | Barlow Condensed | 600 | SIL OFL 1.1 |
| `barlow-condensed-700.woff2` | Barlow Condensed | 700 | SIL OFL 1.1 |
| `inter-var.woff2` | Inter (variable) | 100-900 | SIL OFL 1.1 (`OFL-Inter.txt`) |

The condensed face is the broadcast display face (scores, stat values, labels, REPLAY wipe).
Inter is the UI face (sentences, metadata, tags). Numerals are tabular.
